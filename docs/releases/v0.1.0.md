# AeroForge v0.1.0 — Initial Public Release

AeroForge is a C++20 six-degree-of-freedom aerospace simulation, guidance/navigation/control (GNC), visualization, and software/physical hardware-in-the-loop (HIL) engineering platform.

## Included

- Modular rigid-body 6DOF dynamics and Euler/RK4 numerical integration.
- Atmosphere, aerodynamics, rocket propulsion, variable mass/inertia, sensors, navigation, GNC, actuators, fault injection, Monte Carlo experiments, and repeatable simulations.
- A Windows desktop visualizer supporting recorded telemetry, live 6DOF simulation, synthetic-display testing, 3D attitude, plots, events, and HIL monitoring.
- Software HIL and experimental ESP32 serial HIL with packet validation and command-freshness watchdog/fallback handling.
- Three short demo videos: rocket-flight telemetry playback, live 6DOF simulation, and GNC/software HIL.

## Verification

A clean Windows x64 Release build passed **1,557 registered CTest tests** on October 30, 2026, and the visualizer was launched and manually checked. Independent GitHub Actions release-build results should also be reviewed before publication.

Historical measured HIL workloads, verification methods, and caveats are in `docs/verification/CurrentVerificationResults.md` and the repository README. Performance measurements are specific to the tested systems and workloads, not general real-time guarantees.

## Known limitations

- The full guided-rocket reference mission has **not** been comprehensively integrated or validated against real flight data.
- The physical ESP32 HIL benchmark **did not meet** its fresh-command acceptance threshold: 641 newly accepted replies for 1,000 simulated 100 Hz steps, despite 997 steps using a still-valid command and zero observed simulation deadline misses.
- The physical HIL USB disconnect/reconnection and applied-command failsafe behavior have not been fully signed off; physical HIL is experimental and not suitable for commanding real actuators or safety-critical equipment.
- Windows x64/MSVC is the tested desktop build configuration; portability and redistributable runtime dependencies should be evaluated on other systems.

## Getting started

Download `AeroForge-windows-x64.zip`, extract it, and run `AeroForgeVisualizer.exe` on a supported Windows machine with OpenGL-capable graphics. The package includes README/documentation and demonstration media; building from source and running CTest requires the development toolchain described in `docs/INSTALL_AND_VALIDATION.md`.

The release is intended for engineering education, experimentation, and software demonstration, **not** flight certification or safety-qualified hardware control.
